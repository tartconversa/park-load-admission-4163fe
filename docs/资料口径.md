# 资料口径

主体、设备和数值全部合成，不代表真实企业或实验结果。CSV 为 UTF-8，空值表示未知或不适用，不能当成零；布尔为 true/false。日期采用 ISO 格式，时刻带 +08:00 时区；日期区间左闭右开。金额为人民币元，概率为 0–1，除字段另有声明外数量为非负。CSV 排序不代表事件顺序。available_at 表示该事实最早可知时刻，历史截点不可使用较晚才知的值。样本用于开发，业务结论未预设。

kwh为半小时能量，转换平均功率需考虑时长；incoming进线与tenant分表有覆盖映射，覆盖外不代表零。missing_type的communication为失联、shutdown为已知停产；后者可真实零。curtailment requested_kw为请求削减功率，actual_kw为已核实削减，rebound_kwh为次日回补能量；零请求表示未接受通知，非零请求而响应零为未响应。柔性合同限制连续调用次数与通知提前小时；acceptance_probability是可比历史条件下的登记接受概率，不是响应概率。接入总容量为1500千瓦，超限容忍概率由申请条件给定。

## tenants
园区现存企业。

记录键：['tenant_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| tenant_id | string | 企业 |
| process | string | 工艺 |
| rated_kw | number | 铭牌功率 |
| shift | string | 班次 |

## coverage
分表覆盖边界；IN为公共进线。

记录键：['meter_id', 'start']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| meter_id | string | 分表 |
| tenant_id | string | 企业 |
| start | date | 开始 |
| end | date | 结束 |

## metering
各日选定窗口的半小时完整时段；未提供全天。

记录键：['reading_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| reading_id | string | 读数 |
| meter_id | string | 表 |
| date | date | 日 |
| hour | number | 半小时起点 |
| kwh | number | 能量 |
| missing_type | string | 缺测或生产状态 |
| available_at | datetime | 可知时点 |

## production

记录键：['tenant_id', 'date']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| tenant_id | string | 企业 |
| date | date | 日 |
| state | string | 生产或停产 |
| output_index | number | 产量指数 |

## response_history
实际通知含未接受，不由观测直接指定效果模型。

记录键：['event_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| event_id | string | 事件 |
| tenant_id | string | 企业 |
| date | date | 日期 |
| notice_hours | number | 提前小时 |
| requested_kw | number | 已接受请求 |
| actual_kw | number | 核实响应 |
| rebound_kwh | number | 次日回补 |
| consecutive_calls | integer | 连续调用次数 |
| acceptance_probability | number | 接受登记概率 |
| available_at | datetime | 可知时点 |

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| offer_id | string | 方案 |

| max_kw | number | 可调上限 |

| min_gap_days | integer | 调用间隔 |
| max_consecutive | integer | 最大连续调用 |
